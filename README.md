## Mini-Projeto Avaliativo - Análise Exploratória de Dados (Base Varejo)

Este repositório contém a solução do Mini-Projeto Avaliativo do Módulo 1 (Semana 07) para a disciplina de Visualização de Dados e Business Intelligence.

📌 Objetivo do Projeto
O objetivo principal é realizar uma Análise Exploratória de Dados (AED) em uma base de varejo usando a biblioteca pandas em Python, abordando etapas de carregamento, limpeza, tratamento de inconsistências, análise estatística e geração de insights de negócio.
